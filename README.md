# 🏰 國小國語 3D 期末奇幻大冒險（115 學年度第一學期・南一版）

🎮 **線上立即遊玩（公開連結）**：[https://dingqianworking-dotcom.github.io/chinese-3d-adventure/](https://dingqianworking-dotcom.github.io/chinese-3d-adventure/)

專為國小一年級、二年級設計的 3D 皮克斯奇幻風國語期末總複習互動遊戲，支援電腦、平板與手機直接開啟遊玩！

- **🐣 一年級（第 1～7 課＋期末大魔王決戰）**：`小船`、`印手印`、`吹泡泡`、`你好`、`外星人`、`小金魚`、`紅紅的春`

## ✨ 遊戲特色
- **台灣教育部標準直式注音**：所有標靶、泡泡、國字右側標音、課文閃卡與詳解皆採用標準直式注音排版。
- **消音注音考驗**：射飛鏢與消音泡泡題型自動將目標字消音，真正檢測注音拼讀與多音字實力。
- **多元互動關卡**：🎯 奇幻射飛鏢、🫧 消音泡泡、🔨 草地打地鼠改錯字、🧪 部件魔法鍋、🚂 句型小火車、🐉 期末星光砲打魔王、🎰 3D 神獸扭蛋屋。
- **全 13 課專屬 3D 場景與互動聲光**：每課皆具備專屬 3D 奇幻圖示、全景視差舞台與主題合成音效。
